# 部署说明（阿里云服务器）

适用于一台装了 Linux（Alibaba Cloud Linux、Ubuntu、CentOS 均可）的云服务器。没有域名时，先用 `http://服务器公网IP` 访问即可。

## 1. 服务器准备

**安全组**（阿里云控制台 → 云服务器 ECS → 安全组）：放行入方向 `80`（网页）和 `22`（SSH）。有域名后再放行 `443`。**不要**开放 5432（数据库）。

**安装 Docker：**

```bash
# Alibaba Cloud Linux / CentOS
sudo yum install -y docker && sudo systemctl enable --now docker
# 或 Ubuntu
sudo apt update && sudo apt install -y docker.io docker-compose-v2 && sudo systemctl enable --now docker

docker compose version   # 确认有 compose 插件
```

**配置镜像加速**（大陆服务器从 Docker Hub 拉镜像通常很慢或失败）：
在阿里云控制台搜索“容器镜像服务 ACR” → 镜像工具 → 镜像加速器，复制你的专属加速地址，然后：

```bash
sudo mkdir -p /etc/docker
echo '{ "registry-mirrors": ["https://你的加速地址.mirror.aliyuncs.com"] }' | sudo tee /etc/docker/daemon.json
sudo systemctl restart docker
```

同时建议打开项目 `Dockerfile` 里 `npm config set registry https://registry.npmmirror.com` 那一行的注释。

## 2. 获取代码

```bash
git clone https://github.com/SaberAlterP/teaching-platform.git
cd teaching-platform
```

仓库是私有的，clone 时需要 GitHub 用户名和 [Personal Access Token](https://github.com/settings/tokens)（不是登录密码）。大陆服务器访问 GitHub 不稳定时，也可以在自己电脑上把项目打包成 zip，用 `scp` 传到服务器。

## 3. 配置并启动

```bash
cp env.production.example .env
# 生成两个随机密钥填进 .env
openssl rand -hex 16   # → DB_PASSWORD
openssl rand -hex 32   # → AUTH_SECRET
nano .env              # 或 vi .env

docker compose up -d --build        # 第一次构建约 3–8 分钟
docker compose exec app node scripts/seed.mjs   # 只需执行一次：创建教师账号和示范课
```

浏览器打开 `http://服务器公网IP`，用 `.env` 里设置的教师账号登录（默认 `teacher` / `teacher123`，首次登录会要求改密码）。

> 想要演示数据（30 个演示学生和模拟成绩）：`docker compose exec app node scripts/seed.mjs --demo`（只能在全新数据库上执行）。

## 4. 更新版本

```bash
cd teaching-platform
git pull
docker compose up -d --build     # 数据库迁移会在启动时自动执行
```

数据库和上传的文件保存在 Docker 数据卷里，重新构建不会丢失。

## 5. 备份

```bash
# 手动备份数据库
docker compose exec -T db pg_dump -U tp teaching | gzip > backup_$(date +%F).sql.gz

# 每天凌晨 3 点自动备份，保留 14 天（crontab -e 添加一行，路径按实际修改）
0 3 * * * cd /root/teaching-platform && docker compose exec -T db pg_dump -U tp teaching | gzip > /root/backups/tp_$(date +\%F).sql.gz && find /root/backups -name 'tp_*.gz' -mtime +14 -delete
```

上传的文件在 `uploads` 数据卷中（`docker volume inspect teaching-platform_uploads` 可查看位置），建议一起备份。

恢复：`gunzip -c backup.sql.gz | docker compose exec -T db psql -U tp teaching`

## 6. 有域名之后：开启 HTTPS

1. 域名解析到服务器 IP（大陆服务器需先完成 ICP 备案）。
2. 在 `docker-compose.yml` 里把 app 的端口改成 `"127.0.0.1:3000:3000"`，然后在服务器上用 Caddy 做反向代理（自动申请免费证书）：

```bash
# /etc/caddy/Caddyfile
你的域名.com {
    reverse_proxy 127.0.0.1:3000
    request_body {
        max_size 210MB
    }
}
```

3. `.env` 里设置 `COOKIE_SECURE=true` 和 `TRUST_PROXY=true`，然后 `docker compose up -d`。

## 7. 容量参考

- 2 核 4G 可以支撑几百名学生同时上课。
- 主要瓶颈是**带宽**：几百人同时打开一个 5MB 的动画，就是 GB 级的瞬时流量。按固定带宽计费的小带宽服务器，建议把大视频放到对象存储（OSS）+ CDN，在“图片 / 视频”模块里填链接即可。

## 常见问题

- **页面打不开**：检查安全组是否放行 80 端口；`docker compose ps` 看容器是否在运行；`docker compose logs app` 看报错。
- **登录后又跳回登录页**：用 http 访问时 `.env` 里的 `COOKIE_SECURE` 必须是 `false`。
- **上传大文件失败**：如果前面有 Nginx/Caddy，需要调大请求体上限（见上面的 `max_size`）。
